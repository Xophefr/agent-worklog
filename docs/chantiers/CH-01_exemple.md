# CH-01 · Exemple : mise en place du suivi des chantiers

Doc de reprise d'un chantier : le DÉTAIL (contexte, décisions, mesures, point de départ de la session suivante). L'état tient en une ligne dans `docs/CHANTIERS.md`, les tâches sont dans le backlog.

## Contexte

Pourquoi ce chantier existe, ce qu'il doit changer, pour qui.

## Décisions

- 2026-01-01 : exemple de décision, avec sa date et qui l'a prise.

## Découpage

Une liste numérotée : chaque ligne est un LOT, et nomme ses tâches. Le tableau regroupe alors les tâches du chantier par lot (`SUI-01, 02`, `SUI-01 à 04`, `(03-04)` sont compris).

1. **Brancher le suivi** : agent de code et vrais chantiers (SUI-01, 02)
2. **Mesurer le code** : groupes du relevé et relevé automatique (SUI-03 à 04)

## Reprise

Où on en est, et par quoi commencer la prochaine fois.
